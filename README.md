💻 C Programming Notes
📌 Overview

This repository contains comprehensive notes on **C programming fundamentals**, written for beginner to intermediate learners.  
It covers syntax, data types, operators, input/output handling, functions, and practical sample programs.  

The notes are designed to be **academic-friendly** and include explanations, code snippets, and outputs for better understanding.

---

🧑‍💼 Topics Covered

### 🔹 Basics
- Structure of a C program (`main()` function, return values)
- Printing with `printf()`
- Comments (`//` for single-line, `/* */` for multi-line)

### 🔹 Variables & Data Types
- `int`, `float`, `double`, `char`, `char[]` (strings), `bool`
- Format specifiers (`%d`, `%f`, `%lf`, `%c`, `%s`)
- Width, precision, and flags in formatting

### 🔹 Operators
- Arithmetic operators (`+`, `-`, `*`, `/`, `%`, `++`, `--`)
- Augmented assignment (`+=`, `-=`, `*=`, `/=`)
- Logical operators (`&&`, `||`, `!`)

### 🔹 Input Handling
- `scanf()` for basic input
- `fgets()` for strings with spaces
- Handling null terminators and whitespace

### 🔹 Control Structures
- `if`, `else if`, `else`
- `switch` statements (with `break` and `default`)
- Nested conditions

### 🔹 Functions
- Defining and calling functions
- Parameters vs arguments
- `return` keyword
- Function prototypes
- Variable scope (local vs global)
